# placitum/node

Узел защиты Placitum: nginx с модулем `ngx_http_waf_module` и агент ноды в одном образе.

Модуль принимает трафик и согласует решение по каждому запросу и ответу с внешними
инспекторами через шину сообщений; агент рядом ведёт конфигурацию, аудит, архив и присутствие
узла. Логики детекта здесь нет — она в инспекторах, и они пишутся на любом языке отдельно.

```
клиент ──► nginx + ngx_http_waf_module ──► приложение
               │  волны инспекторов по шине (NATS)
               │  тело, заголовки и строка запроса -- в обменник по локатору
               ▼
            агент ноды ──► аудит и журнал на шину, архив в S3,
                           конфигурация из KV, пульс на WAF_STATUS
```

## Что здесь лежит

| Каталог | Что это |
| --- | --- |
| `module/` | сам модуль: исходники на C, `config` для сборки, юнит-тесты конфигурации, фаззинг |
| `agent/` | агент ноды на Go: конфигурация из KV, аудит, архив, журнал nginx, пульс |
| `managed/` | образ управляемого узла: nginx + модуль + агент, точка входа |
| `pages/` | страницы отказа из образа: то, что перекрывают страницы контроллера |
| `tests/` | прогоны: юнит-конфиги, дым, шина, WebSocket, нагрузка |
| `docs/` | устройство модуля и агента, известные проблемы, документация прогонов |

## Сборка

Образ управляемого узла — модуль, агент и страницы в одном:

```sh
docker build -f managed/Dockerfile -t placitum/node .
docker buildx build -f managed/Dockerfile -t placitum/node \
  "https://github.com/exemt/placitum-node.git#develop"
```

`NGINX_VERSION` (по умолчанию `1.28.0`) — общая и для сборки модуля, и для базового образа:
модуль, собранный против других исходников, даёт порчу памяти, а не ошибку загрузки.

Только модуль, без образа узла — `module/Dockerfile`.

## Как узел работает в контуре

До первого поколения от контроллера узел отвечает заглушкой `503` на `:8079` — это нормальное
состояние свежей ноды, а не отказ. Конфигурацию присылает контроллер, агент применяет её через
`nginx -s reload` и отвечает в пульсе, применилось ли.

Имя узла (`WAF_NODE_ID`) должно совпадать с `waf_node_id` в конфиге модуля: по нему ноду видно
в панели, в пульсе и в аудите.

Что нужно рядом: шина NATS, обменник Redis, внутренний Redis для блобов поколения и S3 для
архива. Переменные, конфиг агента и раскладка — [INSTALL.md](INSTALL.md).

## Ветки

`develop` — то, что разрабатывается: сюда приезжает каждая выкладка. `main` — выкаченные сборки.
Правок в этом репозитории не делают: обе ветки производные от платформы.
