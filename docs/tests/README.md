# Прогоны модуля

Четыре слоя, от дешёвого к дорогому. Каждый следующий проверяет то, чего
предыдущий не видит по устройству, а не по недосмотру.

| прогон | что поднимает | что проверяет | сколько идёт |
| --- | --- | --- | --- |
| [`nginx/tests/unit`](../../tests/unit) | ничего, `nginx -t` | разбор директив, слияние уровней, отказы конфигурации | секунды |
| [`nginx/tests/smoke`](smoke.md) | один контейнер | живой запрос: контекст, локальный слой, вердикт, лог | ~5 с |
| [`nginx/tests/bus`](bus.md) | NATS, Redis, поддельные инспекторы, настоящий modsec, приёмник итогов | волны, размещение объектов, вердикты, счёт, дедлайны, обе фазы, запись аудита | ~40 с |
| [`nginx/tests/ws`](websocket.md) | NATS, Redis, настоящие modsec и json, приложение WebSocket | рукопожатие через фазу запроса, кадры клиента через фазу `frame`: CRS по содержимому, схема по типу сообщения, Close по вердикту | ~50 с |
| [`nginx/tests/ws/load.mjs`](websocket.md#нагрузка) | тот же стенд без rewrite, счётчик с профилем `wsload`, облегчённый CRS | лестница скоростей до упора на эхо с телами 1–12 КБ: `waf off`, боевой маршрут (счётчик вход/выход + CRS), модуль без инспекторов; задержка, потери, закрытия, CPU контейнеров | ~5 мин |
| `tests/e2e` (`tests/e2e`), [`nginx/tests/load`](load/README.md) | весь контур `deploy/` | настоящие инспекторы, агент, контроллер, ClickHouse, нагрузка | минуты |

Все прогоны, кроме последнего, создают собственную сеть и собственные
контейнеры со своим префиксом имени и удаляют их за собой: запущенный рядом
`deploy/` они не трогают.

```sh
node nginx/tests/unit/run.mjs     # nginx -t на всех конфигурациях
node nginx/tests/smoke/run.mjs    # живой запрос без внешних зависимостей
node nginx/tests/bus/run.mjs      # волны и вердикты через шину
node nginx/tests/ws/run.mjs       # вебсокет в обе стороны
node nginx/tests/ws/load.mjs      # кадры под нагрузкой: лестница до упора
```

Образ берётся из `WAF_NGINX_IMAGE`, по умолчанию `waf-nginx`. Собрать:

```sh
docker build --target runtime -t waf-nginx nginx/module
```

`--target runtime` обязателен: последняя цель Dockerfile — `artifact`, в ней
нет ни nginx, ни оболочки, только `.so`.

## Чего эти прогоны не заменяют

Ни один из них не проверяет агента, ClickHouse, S3 и контроллер: там свои
прогоны в `tests/`. Нагрузка и поведение под давлением — `nginx/tests/load`
для запросов и `nginx/tests/ws/load.mjs` для кадров.
